# 🔗 Merge & Sort Two Lists

Небольшой Python-скрипт, который объединяет **два списка**, сортирует результат и показывает первые и последние элементы.

---

## ✨ Возможности

- 🔗 Объединение двух списков в один
- 🔃 Сортировка объединённого списка по возрастанию
- ✂️ Вывод первых 3 элементов (срез `[:3]`)
- ✂️ Вывод последних 3 элементов (срез `[-3:]`)
- 🧩 Отдельная функция `add_list()`

---

## 🚀 Запуск

```bash
python main.py
```

---

## 💻 Пример работы

**Исходные списки:**
```python
first_list  = [1, 2, 5, 6, 7]
second_list = [1, 4, 6, 10, 20]
```

**Вывод:**
```
[1, 1, 2, 4, 5, 6, 6, 7, 10, 20]
[1, 1, 2]
[7, 10, 20]
```

---

## 🧠 Как это работает

### `add_list(one_list, two_list)`

1. Объединяет два списка через оператор `+`
2. Сортирует результат через `sorted()`
3. Возвращает новый отсортированный список

```python
def add_list(one_list, two_list):
    done_list = one_list + two_list
    sorting = sorted(done_list)
    return sorting
```

### Срезы для вывода

| Срез | Что делает |
|------|-----------|
| `[:3]` | Первые 3 элемента |
| `[-3:]` | Последние 3 элемента |

```python
print(add_list(first_list, second_list))         # весь список
print(add_list(first_list, second_list)[:3])      # первые 3
print(add_list(first_list, second_list)[-3:])     # последние 3
```

---

## ⚠️ Замечание по коду

Функция `add_list()` вызывается **3 раза** — а значит, объединение и сортировка выполняются 3 раза заново. Это неэффективно.

### ✅ Лучше сохранить результат в переменную:

```python
result = add_list(first_list, second_list)

print(result)        # весь список
print(result[:3])    # первые 3
print(result[-3:])   # последние 3
```

Так код работает быстрее и читается легче.

## 💡 Альтернативные способы

### 1. Через `sorted()` в одну строку
```python
def add_list(one_list, two_list):
    return sorted(one_list + two_list)
```

### 2. Через `extend()` (меняет первый список)
```python
def add_list(one_list, two_list):
    one_list.extend(two_list)
    return sorted(one_list)
```

### 3. Удалить дубликаты после объединения
```python
def add_list(one_list, two_list):
    return sorted(set(one_list + two_list))
```

---

## ⚖️ Сравнение `sorted()` и `.sort()`

| Способ | Возвращает | Меняет оригинал? |
|--------|-----------|------------------|
| `sorted(list)` | Новый список | ❌ Нет |
| `list.sort()` | `None` | ✅ Да |

В коде используется `sorted()` — это безопаснее, потому что оригинальные списки не меняются.
